<a id="provenance-rule"></a>
<sub><strong>36 // Provenance rule</strong></sub>

Prefer, in order: provider-owned repository → canonical maintainer repository → clearly labeled community client/integration. Do not silently convert a third-party wrapper into an “official SDK.”
